# 余响 Afterglow

独立融合 Demo：沉浸播放 → 点歌词记录 → 创作空间 → 笔记工作台 → 回看与回听。原有 `Mineradio-paused` 和 `EchoPulseNode` 无需安装或运行，原工程未修改。

## 运行

要求 Node.js 22.12+ 或 24 LTS。

```powershell
cd c:/Users/yehanyang/Desktop/epnn/Afterglow
npm install
npm run dev
```

打开 http://127.0.0.1:5178 。API 固定为 http://127.0.0.1:3108 。两个端口必须空闲。

```powershell
npm run build
npm start
```

生产预览使用 http://127.0.0.1:3108 。开发与生产是不同 origin，本地笔记不会自动跨端口迁移。

## 体验

- 点击播放：播放运行时合成的 72 秒氛围音。文字为原创演示，按示例时间轴展示，不是人声歌词对齐。
- 点击一句歌词，再点“记录此刻”；或按 `Alt + N`。
- 翻书进入创作空间，点击“打开我的工作台”，直接写笔记。歌曲不因视图切换而中断。
- 笔记自动保存，标题可空。回听从关联片段前 3 秒开始。
- 瞬间素材库支持本地关键词搜索、回看、删除、单篇 Markdown 导出与全部 JSON 备份导出。
- 导入浏览器支持的音频（上限 100 MB），同时粘贴或读取 LRC / YRC / TXT 歌词。普通文本不假装有时间轴。
- 切换歌曲不会改变当前笔记的来源，分析使用笔记所属歌曲，而不是正在播放的另一首。

## 数据与隐私

音频、笔记都保存于当前浏览器的 IndexedDB，不上传音频，不向模型发送私人笔记。保存成功仅指浏览器本地事务完成；清理网站数据、换浏览器或换端口都会影响可见数据。请定期导出笔记。当前 JSON 备份仅提供导出，尚无一键恢复界面。

当前是单用户本地原型，无登录、云同步、录音、自主素材整理 Agent、在线视频导出或商业音乐源。建议继续保留源音频文件。网页仅绑定回环地址，不应直接暴露到公网。

## EPN 分析

真实复用 `vendor/epn` 中的 EPN 分析服务，而非模拟押韵结果。默认无需密钥，以规则方式运行。每次分析最多 12,000 字 / 200 行；并发 2，单分钟 20 次。

如需 LLM：将 `.env.example` 复制为本工程 `.env`，填入配置并设置 `USE_REAL_LLM=true`，重启 API。`LLM_API_URL` 必须是完整的 OpenAI-compatible chat-completions 地址。未读取原 EPN 的任何凭据。

点击分析时只发送歌词和曲目信息；启用 LLM 后这些内容会发送至所配置模型。模型请求设 45 秒超时，失败使用原 EPN 的规则回退并明确标识。情绪值是文本推断，不是真实音频能量、专业 Flow 评分或用户心理判断。韵脚颜色按返回字符区间展示，无法与原文核对的区间不强行高亮。


端到端测试自动使用 5178 开发端口；已有服务时会复用。测试在隔离浏览器上下文中执行，不改真实用户笔记。

## 融合范围

- Mineradio：按 GPL 来源声明适配 LRC / YRC 解析，重新实现 Web 播放器、频谱响应氛围画布与视觉舞台。未复制原 Electron 壳、在线音乐源或全部 3D 引擎。
- EchoPulseNode：复制最小真实分析服务依赖集，工作台 UI 为新实现；新增个人笔记和片段关联。
- 新部分：持久化音频与瞬间、本地检索、导出、同一音频实例跨视图播放、原创唱片视觉、翻书转场。
